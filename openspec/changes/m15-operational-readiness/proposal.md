# M15 operational readiness

The first long adaptive run demonstrated transferable approach and shooting,
but it used the M14 configuration and degraded on progress while never learning
defensive or passing holdouts. M15 needs an explicit actor-only warm start,
bounded exploration, periodic semantic evaluation, and a dedicated launch
recipe before another high-budget run is safe.

This change adds an explicit policy warm start, bounded exploration, and
checkpoint selection. It completes that operational boundary without changing simulator
physics or authorizing physical M12 work.
